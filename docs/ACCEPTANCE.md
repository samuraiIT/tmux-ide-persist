# Проверка первой версии

Дата: 23.10.2026. Цель: независимый публичный комплект для сохранения
интерактивного Linux-терминала при отключении IDE/SSH.

- `bash -n bin/ide-tmux install.sh`: PASS.
- `python3 tests/smoke.py`: PASS на tmux 3.4/Linux.
- Smoke: отдельный Unix socket, настоящий PTY attach, detach клиента,
  сохранение PID и доступности процесса, persistence/mouse/right-click guard.
- `git diff --check`: PASS перед публикацией.
- Публикуется только дерево этого проекта; исходный server config и его
  приватные документы исключены. Настройки исходного сервера не менялись.

Не проверено автоматически: физический reconnect конкретной IDE, клиентский
clipboard/scroll, macOS и WSL. Пользовательский сценарий описан в README.

Откат установки: проверить и удалить только созданный symlink, вручную убрать
добавленный профиль IDE. Запущенные сессии не завершать массово.
